# 本地化教材檢索與人工智慧輔助複習系統

本專題以使用者指定的 PPT、PDF 課程教材為資料來源，建置一套本地化教材檢索與 AI 輔助複習系統。

系統可擷取教材中的文字、圖片與 OCR 內容，建立教材向量索引，並提供教材查詢、內容整理、關鍵字提示、選擇題生成、練習與測驗等功能。

查詢與題目結果會保留教材檔案、頁碼、圖片等來源資訊，使使用者能回到原始教材確認內容。

---

## 專題目標

- 擷取 PPT、PDF 教材中的文字、圖片與 OCR 內容
- 將教材整理為可供檢索的結構化資料
- 建立指定教材範圍的向量索引
- 支援直接文字比對與向量檢索
- 根據檢索結果進行教材限定的 AI 內容整理
- 提供關鍵字提示、選擇題、練習與測驗功能
- 保留教材檔案、頁碼與圖片等來源資訊
- 讓使用者能由查詢或題目結果回到原始教材頁面確認內容

---

## 已完成功能

### 1. 教材上傳與前處理

- 建立科目資料夾並上傳 PPT / PDF 教材
- 擷取教材中的文字與圖片
- 使用 Tesseract OCR 補充圖片中的文字資訊
- 將處理後的教材整理為 JSONL
- 保留教材識別資訊、頁碼、圖片與 OCR 結果

### 2. 複習範圍與向量索引

系統可依使用者指定的教材範圍整併資料，再建立對應的向量索引。

目前向量建立流程包含：

- 使用 `sentence-transformers/all-MiniLM-L6-v2` 進行文字編碼
- 使用 attention mask 進行 mean pooling
- 對向量進行 L2 normalization
- 使用 FAISS `IndexFlatIP` 建立向量索引
- 索引之外另外保存教材頁面與來源資訊

### 3. 教材內容查詢

教材查詢採用直接文字比對與向量檢索兩種方式。

查詢流程為：

1. 優先尋找教材中的直接文字命中結果
2. 若沒有直接命中，再使用向量檢索尋找語意相關內容
3. 顯示教材文字、OCR、圖片與來源頁碼
4. 保留來源資訊，供使用者開啟對應教材頁面

一般教材查詢主要呈現原始教材內容，不需由生成式語言模型重新產生答案。

### 4. AI 內容整理

當使用者選擇內容整理功能時，系統會先取得相關教材片段，再將檢索結果組成 context，交由本地語言模型整理。

目前支援：

- 一般問答
- 重點整理
- 比較
- 流程整理

系統透過提示規則要求模型依提供的教材內容回答；若目前取得的教材資訊不足，則要求模型標示資訊不足，而非直接使用教材外知識補充。

> 注意：目前主要透過提示規則限制生成內容，尚未建立逐句來源支持驗證。因此，候選來源清單代表本次檢索取得的教材頁面，不代表生成內容中的每一句都已被自動驗證。

### 5. 關鍵字功能

系統可依指定教材範圍產生複習用關鍵字。

目前支援：

- 使用本地語言模型輔助產生或篩選
- 使用規則或統計方式產生
- 將產生的關鍵字載入查詢介面
- 點選關鍵字後快速填入查詢內容
- 使用者亦可完全不使用關鍵字，自行輸入問題

### 6. 選擇題與測驗

系統可依目前教材範圍產生四選一題目，並保存：

- 題幹
- 四個選項
- 正確答案
- 答案解析
- 教材來源資訊

前端提供兩種作答方式：

**練習模式**

- 每題作答後可查看答案
- 顯示解析與教材來源
- 可開啟來源教材頁面確認內容

**測驗模式**

- 完成整份題目後統一提交
- 計算答對題數、錯題數與正確率
- 顯示答案、解析與來源

系統亦提供：

- 錯題導航
- 作答結果保存
- 歷史測驗紀錄
- 歷史題目、選項、答案、解析與來源重新查看

### 7. 教材來源回溯

教材在前處理階段即保留檔案與頁碼等資訊。

因此查詢或作答後，使用者可開啟對應教材頁面，查看：

- 原始文字
- OCR 辨識結果
- 原始圖片
- 教材頁碼

保留原圖的目的之一，是讓使用者在 OCR 對公式、符號或複雜版面辨識不完整時，仍能回到原始教材人工確認。

### 8. 前端操作介面

前端目前包含：

- 教材上傳
- 教材前處理
- 複習範圍建立
- 教材查詢
- 內容整理
- 關鍵字操作
- 選擇題練習與測驗
- 教材來源檢視

查詢、教材檢視與作答頁面亦針對不同螢幕寬度進行版面調整。

## 執行環境

本專案主要於 Windows 與 Conda 環境開發。

### 1. 建立並啟用 Conda 環境

```bash
conda create -n llmenv python=3.11
conda activate llmenv
```

### 2. 安裝 Python 套件

```bash
pip install -r requirements.txt
```

PyTorch 請依本機 CUDA 環境安裝對應版本。

FAISS 可透過 Conda 安裝：

```bash
conda install -c conda-forge faiss-cpu=1.9.0
```

### 3. 安裝外部工具

執行教材前處理及本地模型功能前，需另行準備：

- Tesseract OCR
- Poppler
- Ollama
- 專案使用的本地語言模型

### 4. 啟動系統

執行：

```text
start_system.bat
```

系統會啟動：

- FastAPI 後端：`http://127.0.0.1:8000`
- 前端伺服器：`http://127.0.0.1:5500`
- 系統入口：`http://127.0.0.1:5500/launcher.html`

停止系統時執行：

```text
stop_system.bat
```

## 目前限制

目前系統以功能整合、實際教材操作與人工確認為主，仍有以下限制：

- OCR 結果會受到圖片解析度、公式、字體與版面配置影響
- 向量檢索結果會受到教材文字品質與 Embedding 模型影響
- 語意相近的檢索結果不代表一定符合使用者需求
- 本地語言模型的整理結果仍可能出現不穩定情況
- 提示規則無法保證完全排除教材外資訊
- 候選來源頁面不等同於逐句來源支持驗證
- 尚未建立完整的教材檢索人工標註題集
- 尚未進行大規模量化的檢索準確率、生成品質與學習成效評估

---

## 後續方向

後續預計從資料與檢索證據開始進一步評估，包括：

- 建立具有人工標註證據的檢索評估流程
- 比較不同文字切分設定對檢索結果的影響
- 比較不同 overlap 與 top-k 設定
- 分析設定改變後必要證據是否仍被保留
- 記錄並分析檢索失效來源
- 加入更完整的來源支持驗證
- 改善圖片、圖表與公式內容處理
- 評估檢索品質、生成品質與系統延遲

目前研究延伸方向為：

**「檢索增強生成系統於檢索設定變動下之證據連續性與失效來源分析」**
